LV24 SEO Optimizer Desktop 0.9.1 adds OAuth Connect buttons for Google Search Console, Yandex Webmaster and Yandex Metrika on engine 0.13.1.

The Integrations screen has a Connectors card. Google runs the engine's loopback OAuth flow (the system browser opens and the card waits for consent); Yandex and Metrika show the authorization URL, take the verification code from oauth.yandex.ru/verification_code, and finish the exchange. Tokens stay in the OS keychain and are never shown in the UI. The client secret is configured once with lv24-seo auth set --provider gsc_oauth_secret|yandex_oauth_secret --stdin.

The bridge allow-lists auth login and rejects write flags, invalid provider/port/code combinations and any URL outside https://oauth.yandex.ru/authorize. The card has no write or confirm controls.

The bundled engine is lv24-seo 0.13.1 with 25 CLI commands, 12 MCP tools and SQLite schema 5. MIN_ENGINE_VERSION is now 0.13.1. Live OAuth consent still needs a registered Google Desktop client and Yandex OAuth app; until then the card shows the engine's setup error.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the portable ZIP are manual-only. 0.9.0 to 0.9.1 is the next in-app update. OS packages remain unsigned (Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
