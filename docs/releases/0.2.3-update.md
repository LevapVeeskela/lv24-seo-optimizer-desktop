LV24 SEO Optimizer Desktop 0.2.3 is a security and hardening release.

The updater install now runs in Rust: it re-checks the announced version, refuses
a mismatch with UPDATE_VERSION_MISMATCH, downloads with progress, and cancels a
download for real with UPDATE_CANCELLED. The webview no longer has the broad
updater permission; it can only ask the shell to check. Tracked engine sidecars
are stopped before the installer starts, and the Unix process-group kill uses an
explicit `--` so a signal cannot hit the caller's own group.

Engine output is redacted before it reaches the webview: stderr, error previews
and TOML syntax errors can no longer display a token. Config writes require a
path chosen in the native dialog (PATH_NOT_APPROVED otherwise), UNC/device paths
are rejected before they are resolved, open_path opens the canonical path, and
Windows drafts/backups get an owner-only DACL. Large writes and path resolution
run off the UI thread.

The UI fixes the skip-link route, keeps edits typed during a save round-trip,
shows a moved/deleted workspace banner from configExists, adds a per-provider
enable/disable toggle, returns a tri-state validation result, adds a route error
boundary, and localizes recommendation text in en/ru/zh.

The bundled engine is lv24-seo 0.5.3: honest GSC totals and data age, Metrika
paging, Bing row-date age, Yandex empty-history reporting, safer crawl rules and
robots matching, two-phase MCP write gating, --strict with exit 5, --config-aware
write replay protection, safe crontab repair, typed STORE_* errors and a doctor
data_dir gate. MIN_ENGINE_VERSION remains 0.5.2.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage;
deb, rpm, MSI and the portable ZIP are manual-only. 0.2.2 to 0.2.3 is the next
in-app update. OS packages remain unsigned (Windows/Linux) or ad-hoc signed
(macOS); verify SHA256SUMS.txt.
