LV24 SEO Optimizer Desktop 0.2.1 is a patch release.

It fixes the Yandex Metrika token in Settings and the secret modal, and makes
the shared OS keychain explicit: tokens entered with `lv24-seo auth set` in the
CLI are visible in the desktop and vice versa. A signature failure now stays
blocked for that artifact across restarts.

Auto-update works from 0.2.0 for Windows NSIS, macOS `.app` and Linux AppImage;
deb, rpm, MSI and the portable ZIP are manual-only. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify `SHA256SUMS.txt`.
