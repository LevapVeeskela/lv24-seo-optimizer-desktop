## Changed

### Bundled engine is `lv24-seo 0.15.3`

The sidecar pin, the workflow `engine_version` input default, `MIN_ENGINE_VERSION` and the committed
contracts move together to `0.15.3`. The engine patch release carries:

- **TLS facts survive the response body.** The fetcher reads protocol, cipher and certificate
  details before httpcore clears the SSL object, so the `tls-certificate` crawl rule and
  `FetchResult.tls` no longer lose facts on ordinary `200` responses.
- **CJK ideographs count as words.** Every `U+4E00`-`U+9FFF` ideograph counts as one word, so Chinese
  and Japanese pages no longer look like three-word pages and no longer raise false thin-content and
  soft-404 findings. Latin and Cyrillic thresholds are unchanged.
- **Weekly report email restyle.** `render_html` uses the LV24 palette (dark header/footer, one
  orange accent, KPI cards, rounded tables). Presentation only: text, email-text, subject, Markdown,
  report values and localized labels are unchanged.

The desktop UI, command bridge and write gates are unchanged. The contracts were regenerated from
`0.15.3`; the only diff is the engine version reported in the fixtures, which confirms no CLI shape
change. `MIN_ENGINE_VERSION` is now `0.15.3`, so an older bundled or `LV24_SEO_BIN` engine is
reported as incompatible before a command runs.

## Not changed

- MCP stays at 12 tools, the SQLite schema at version 5 and the CLI at 25 top-level commands.
- No new dependency, no new write surface and no provider call at startup.
- The four crawl rule packs (34 rules), the Indexing automation card, the hidden Windows
  scheduled-job launcher and the two-phase write gates.
- The sidecar stays a PyInstaller onedir tree; only the engine version inside it changes.

## Verification

Local gate on the release commit (Windows host):

```bash
npm run typecheck
npm test
npm run build
npm run contract:check
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
node scripts/verify-sidecar.mjs --root src-tauri/engine \
  --target x86_64-pc-windows-msvc --engine-version 0.15.3 --require-pinned
```

Results: 808 Vitest tests, the full Rust suite, contracts at engine `0.15.3`, and the Windows
sidecar verified against the pinned SHA-256
(`2fd6419c66c0b42bf4a6cf49f1f4acbe593879a312a42d740f478f927e7f119f`, 14,610,289 bytes).
The Linux and macOS pins stay `null` until that sidecar is rebuilt and reviewed on a matching host;
CI rebuilds are recorded, not compared, because PyInstaller output is not byte-reproducible.

## Limitations

- TLS facts describe the connection that served the page; a certificate that changes after the body
  is read is outside this fix.
- The restyled email is best-effort: Outlook desktop drops gradients and some border radii and falls
  back to the solid dark header/footer. The JSON envelope remains the stable surface.
- `0.9.8 → 0.9.9` has not been re-run end-to-end yet; verify the in-app update on Windows NSIS and
  re-check the macOS `.app` and Linux AppImage paths after publish.
- OS packages remain unsigned (Windows, Linux) or ad-hoc signed (macOS). Verify `SHA256SUMS.txt`.
- No downgrades; a rollback is a manual install of an older release.
