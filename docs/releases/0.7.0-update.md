LV24 SEO Optimizer Desktop 0.7.0 adds gated Bing indexing actions and moves to engine 0.9.0.

The Integrations screen can submit the project sitemap to Bing Webmaster and send the sitemap's URLs
to IndexNow. Both are two-phase: review the engine plan, confirm, then apply. A missing Bing key is
reported as AUTH_REQUIRED with a Settings hint, and plan tokens expire with the app session. IndexNow
needs providers.bing.indexnow_key plus the key file hosted at https://<host>/<key>.txt; a changed
sitemap invalidates the plan. Bing Site Scan has no public API: the desktop only opens the official
Bing page and never claims that a scan started. Writes are not cancellable and have no rollback.

The desktop now generates a per-session LV24_SEO_WRITE_SECRET in Rust memory and passes it to every
engine child, so the write gate is never in argv, logs or the webview. The bundled engine is
lv24-seo 0.9.0: Bing SubmitFeed with an idempotency ledger, one-click IndexNow from a bounded
sitemap, and the new providers.bing.indexnow_key/indexnow_key_location settings. MIN_ENGINE_VERSION
is now 0.9.0, so an installed 0.8.x engine is reported as incompatible.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.6.0 to 0.7.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
