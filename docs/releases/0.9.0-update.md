LV24 SEO Optimizer Desktop 0.9.0 adds a read-only Diagnostics screen on engine 0.11.0.

The new sidebar screen has five tabs: Google (URL Inspection and sitemap reads), Yandex (indexing
events, sitemaps and recrawl queue), Bing (pages, daily traffic, six-month crawl buckets, URL index
details and query/page joins), Metrika (organic landing pages, goals, devices, countries, engagement
and bytime) and Core Web Vitals (Lighthouse audits and weekly CrUX history). Every report shows
total, truncation, data age and limitations; provider empties are explicit states, not zeros.

All 18 diagnostics commands are read-only and allow-listed in the Rust bridge. The shell rejects
write flags, confirm tokens, unknown selector values, cross-command arguments and a Bing `--site`
override before the engine starts. There are no write buttons on the screen.

The bundled engine is lv24-seo 0.11.0 with 24 CLI commands, 12 MCP tools and SQLite schema 4.
MIN_ENGINE_VERSION is now 0.11.0, so an installed 0.10.x engine is reported as incompatible.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.8.0 to 0.9.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
