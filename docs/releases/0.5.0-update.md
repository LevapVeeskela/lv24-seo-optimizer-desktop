LV24 SEO Optimizer Desktop 0.5.0 adds restore, host scheduling, a portfolio view and Core Web
Vitals.

Backups can now be restored, not only created. The restore is two-phase: the archive is chosen
through the native dialog, the plan shows hashes, targets and the config action, and nothing is
written until you confirm with the plan token (300-second lifetime). The current database and config
are copied to pre-restore files first, every member hash is re-verified, and the restored database
passes a quick check. Restore replaces files and never merges rows or settings; provider tokens are
not in the archive, so re-authenticate afterwards.

Integrations can install a weekly or daily report on this computer: a cron entry, a systemd user
timer or a Windows task, written only after a confirmation dialog. The print-only artifact is still
available. The new Portfolio page scans one chosen folder (up to 50 projects, three levels) and
compares local crawl, report and issue history across sites without calling a provider; opening a
row switches the workspace through the normal shell flow. Reports now render Core Web Vitals by URL
template and device with field p75, previous values and regressions, or an honest empty state when no
stored field rows exist.

The bundled engine is lv24-seo 0.7.0: backup restore, portfolio list, schema v4 with indexing events,
stored indexing evidence in the change digest and the CWV section. MIN_ENGINE_VERSION is now 0.7.0,
so an installed 0.6.x engine is reported as incompatible. 0.5.0 has no cancel or background run and
no remote-host scheduling.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.4.0 to 0.5.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
