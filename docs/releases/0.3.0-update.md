LV24 SEO Optimizer Desktop 0.3.0 is a workflow release that keeps the 0.2.3 hardening.

The 0.2.3 security work remains in place: update install runs in Rust with a version re-check and
real cancellation, tracked engine sidecars are stopped before the installer starts, engine output is
redacted before it reaches the webview, config paths need the native dialog, UNC/device paths are
rejected, open_path uses the canonical path, Windows drafts and backups get an owner-only DACL, and
blocking file work stays off the UI thread.

0.3.0 adds the workflow around those controls. A project wizard runs lv24-seo init without
overwriting an existing seo.toml, known configs persist across restarts, and the header chip switches
between up to eight recent workspaces with a properties panel on the dashboard. The crawl screen
filters issues by severity, rule and search and exports JSON or CSV. Reports compare the two newest
stored weekly snapshots and export JSON or CSV. Settings get a sticky save bar, Ctrl+S, a
changed-only filter and an app-wide unsaved-draft guard, including window close. Recommendations gain
search, severity sorting and bulk queue/export. Integrations generate MCP snippets for Claude
Desktop, OpenCode, VS Code and Cursor and render a print-only cron/systemd/Windows schedule artifact.
The reporting window (7/28/90 days, 2- or 3-day provider lag) is saved per workspace, and long calls
show elapsed time, the last run, truncation and limitations. 0.3.0 has no cancel or background run.

The bundled engine remains lv24-seo 0.5.3 (MIN_ENGINE_VERSION 0.5.2): honest GSC/Metrika/Bing data
age and caps, hardened crawl parsing, typed store errors, --strict exit codes and two-phase MCP write
gating.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.2.3 to 0.3.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
