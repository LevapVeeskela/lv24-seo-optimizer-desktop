LV24 SEO Optimizer Desktop 0.4.0 is an insights release: crawl logs, tasks, backups and an
attributed report digest.

The Logs page analyzes one local nginx JSON access log with `logs analyze`: a native file picker
approves the file, the engine reads it read-only (100 MiB cap), and the page shows parsed/skipped
lines, crawl waste (redirects, errors, assets, /api/ and tracking parameters), the waste split by bot
and a daily bot rollup with hits, bytes, p95 and share. Bot classes are User-Agent only, so this is
triage, not verified-crawler proof. JSON and CSV export write to the app export folder.

The Tasks page tracks findings through `open`, `in_progress`, `verified` and `dismissed`, with
property/kind/state filters, a bounded list, evidence, allowed transitions and an idempotent add form.
The Backup panel creates a portable .zip with a manifest, a redacted seo.toml and a consistent SQLite
copy; tokens are never included. Restore is not implemented yet: unpack the archive manually. Reports
now render the engine's attributed change digest, pairing material metric changes with crawl,
indexing or page evidence, a confidence and a next action; changes without evidence stay
"unexplained".

The bundled engine is lv24-seo 0.6.0, which adds logs analyze and the 12th MCP tool
seo_log_analysis, the attributed digest, the task lifecycle (schema v3, additive) and backup create.
MIN_ENGINE_VERSION is now 0.6.0, so an installed 0.5.x engine is reported as incompatible; 0.4.0 has
no cancel or background run and no backup restore.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.3.0 to 0.4.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
