LV24 SEO Optimizer Desktop 0.2.2 is a hardening patch release.

The updater now stops only the engine sidecar processes this app started before
it installs, so a locked lv24-seo.exe can no longer break the NSIS update; if
cleanup fails the install is blocked with UPDATE_ENGINE_BUSY instead of failing
halfway. Yandex Metrika keeps its own auth provider and token, the desktop and
the CLI share one OS keychain entry per provider (service lv24-seo),
environment-provided tokens are read-only in the UI, and a logout that deleted
nothing says so. Stale workspace, report, doctor and secret state is cleared,
report/export errors explain themselves, actions are disabled when the engine is
offline or no workspace is selected, and the en/ru/zh catalogues are at parity.
Configuration and settings writes are now fsynced (file and parent directory)
with private 0600 temp drafts and backups, config reads are bounded, settings load
per field, a stale config path no longer blocks startup, Windows reserved names
are rejected in every path component, the AppImage sidecar fallback is fixed and
configuration-validation stderr is redacted.

The bundled engine is lv24-seo 0.5.2: data-dir anchoring, absolute scheduler
paths, a CLI write ledger, sitemap warning redaction, honest GSC row caps and
opt-in redacting logging. MIN_ENGINE_VERSION is 0.5.2.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage;
deb, rpm, MSI and the portable ZIP are manual-only. The updater matrix is
unchanged and 0.2.1 to 0.2.2 is the next in-app update. OS packages remain
unsigned (Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
