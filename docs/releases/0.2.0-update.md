LV24 SEO Optimizer Desktop 0.2.0 adds Linux and macOS installers, signed in-app
updates for Windows NSIS, macOS `.app` and Linux AppImage, and the `lv24-seo
0.5.1` engine.

deb, rpm, MSI and the portable ZIP are manual-only. OS packages are unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify `SHA256SUMS.txt` before
installing. Desktop 0.1.0 has no updater and needs one manual 0.2.0 install.
