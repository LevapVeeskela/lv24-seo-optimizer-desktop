LV24 SEO Optimizer Desktop 0.6.0 adds cancellable background runs and moves to engine 0.8.0.

Crawl, weekly report, log analysis, backup create/restore and host schedule install now run in the
background with a window-wide banner and a Cancel button. Cancel signals only the exact child process
the app started for that run; an unknown or finished run returns false, and a cancelled run is shown
as cancelled rather than as a generic error. Cancellation is not rollback: files already written stay
on disk, and a cancelled restore needs a fresh plan before retrying. There is no job queue.

Schedule install now sends --allow-write only after the confirmation dialog, matching engine 0.8.0,
where schedule install is plan-only by default. The bundled engine is lv24-seo 0.8.0: GSC service
accounts, the cwv collect writer, backup restore --to, schedule status/uninstall, richer Yandex
indicators, the Metrika 1-based offset fix and the Windows JSON output fix. MIN_ENGINE_VERSION is now
0.8.0, so an installed 0.7.x engine is reported as incompatible.

Auto-update works from 0.2.0 for Windows NSIS, macOS .app and Linux AppImage; deb, rpm, MSI and the
portable ZIP are manual-only. 0.5.0 to 0.6.0 is the next in-app update. OS packages remain unsigned
(Windows/Linux) or ad-hoc signed (macOS); verify SHA256SUMS.txt.
