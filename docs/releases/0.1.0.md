# LV24 SEO Optimizer Desktop 0.1.0 (Windows preview)

**Status: preview, Windows x64 only, unsigned, no auto-update.** `0.1.0` cannot discover `0.2.0`;
install `0.2.0` manually once. See [`0.2.0.md`](0.2.0.md).

| | |
|---|---|
| Desktop version | `0.1.0` |
| Bundled engine | `lv24-seo 0.5.0` (PyInstaller onedir sidecar) |
| Platform | Windows 10/11 x64 |
| Assets | `LV24.SEO.Optimizer_0.1.0_x64-setup.exe`, `LV24-SEO-Optimizer_0.1.0_x64-portable.zip`, `SHA256SUMS.txt` |

Requires Windows 10/11 x64 and the Microsoft Edge WebView2 runtime. WebView2 ships with Windows 11
and most updated Windows 10 systems; the installer can fetch it when missing, the portable ZIP
cannot.

## What this build is

A local desktop shell around the `lv24-seo` CLI. It reads and validates `seo.toml`, runs bounded
engine commands, and renders their `--json` envelopes. It is not a hosted service, has no telemetry,
no local HTTP API and does not scrape search result pages. Provider access still comes from the
engine and the user's own free-tier credentials.

## Included

- **Dashboard** from `lv24-seo stats --json`: one card per provider with current values, deltas
  against the previous window, CTR deltas in percentage points, status, row counts, data age,
  truncation and limitations, plus a coverage strip that reports `complete: false` when a configured
  service is missing, failed, empty or truncated.
- **Reports**: build the weekly report (writes `report.json` and `report.html` under
  `<app data>/exports/reports`), read its sections, limitations and warnings, and open the generated
  local HTML in your default browser.
- **Settings**: structured forms for project, providers, report/delivery, crawl, storage and desktop
  preferences; engine validation; field-level `config_patch` saves that keep comments and key order;
  timestamped backups (the last five are kept).
- **Configuration**: effective redacted JSON, read-only Source TOML with secret-looking values
  redacted, saved-vs-draft diff, validation errors, doctor output and `LV24_SEO_*` override names
  (values are never shown). There is no raw TOML editor.
- **Recommendations**: bounded findings from the report and stats, severity/category/source filters,
  Markdown prompt copy and `.md` export, and a local review queue. A packet includes the period,
  provider, query/page, observed values, limitations and the source command.
- **Engine status and diagnostics**: desktop and engine versions in the footer, plus config path,
  resolved path, data directory, doctor checks and validation in the Configuration screen. The
  resolved engine path and source are carried in the shell status payload but are not shown as a
  separate panel in this release.
- **UI languages**: English, Russian and Simplified Chinese for the app chrome.
- **Secrets**: token input is a password field sent once over IPC; the Rust layer pipes it to
  `lv24-seo auth set --stdin`. Values are not stored in the webview or logs.

## Install

### Option A — NSIS installer

1. Download `LV24.SEO.Optimizer_0.1.0_x64-setup.exe` and `SHA256SUMS.txt`.
2. Verify the checksum (see below).
3. Run the installer. It installs for the current user only, so no administrator prompt is
   expected, and it adds a Start menu entry.
4. If SmartScreen appears, choose **More info → Run anyway**. The build is unsigned; see below.
5. Launch **LV24 SEO Optimizer**, open **Settings**, and select your `seo.toml`.
6. Uninstall through **Windows Settings → Apps → LV24 SEO Optimizer → Uninstall**.

### Option B — portable ZIP

1. Download `LV24-SEO-Optimizer_0.1.0_x64-portable.zip` and `SHA256SUMS.txt`.
2. Verify the checksum (see below).
3. Extract the **whole** `LV24 SEO Optimizer` folder. Do not run the executable from inside the ZIP.
4. Run `lv24-seo-desktop.exe`. Keep the `lv24-seo\` folder next to it: the shell resolves
   `lv24-seo\lv24-seo.exe` as its engine.
5. There is no installer and no Start menu entry. To remove it, delete the extracted folder.

"Portable" means no installer. The app still writes its own preferences (`settings.json`) to the
per-user app config folder for `by.lv24.seo.desktop` under `%APPDATA%`; project data stays where
`seo.toml` points.

### First run

The Settings screen accepts an existing `seo.toml`. If you do not have one, create it with the
engine first:

```powershell
# Portable ZIP: the CLI is in the extracted folder.
.\lv24-seo\lv24-seo.exe init --property https://example.com --data-dir .\data
```

No Python installation is required: the engine is bundled. A separately installed engine can be
selected with `LV24_SEO_BIN` (absolute path); the shell records it as source `env` and the footer
shows its version.

## Verify the download

```powershell
$files = @(
  "LV24.SEO.Optimizer_0.1.0_x64-setup.exe"
  "LV24-SEO-Optimizer_0.1.0_x64-portable.zip"
)
$sums = Get-Content .\SHA256SUMS.txt
foreach ($file in $files) {
  $line = $sums | Where-Object { $_ -match [regex]::Escape($file) } | Select-Object -First 1
  if (-not $line) { "FAIL $file (not listed)"; continue }
  $expected = $line.Split()[0]
  $actual = (Get-FileHash ".\$file" -Algorithm SHA256).Hash
  if ($actual -eq $expected) { "OK   $file" } else { "FAIL $file" }
}
```

`Get-FileHash` prints uppercase hex and PowerShell string comparison is case-insensitive, so the
lowercase hashes in `SHA256SUMS.txt` match. If a `.sha256` sidecar is published for the ZIP, it uses
the same `<hash>  <filename>` format. **Do not run a file whose hash does not match.**

## Unsigned build

Neither asset has an Authenticode signature. Windows SmartScreen, Smart App Control or antivirus
software may warn or block them. That is expected for an unsigned preview, not proof that the
download is corrupt — but it is exactly why the checksum check above matters. Do not disable
SmartScreen system-wide.

## Known limitations

- **No auto-update.** The updater is not initialized: no endpoint, no public key, no `latest.json`.
  Check the Releases page and install a newer build manually.
- **Windows x64 only.** No Linux or macOS installers are published for `0.1.0`. The manual workflow
  builds those targets, but they are not release assets yet.
- **Unsaved drafts are session-only.** Settings and Configuration share one in-memory `ConfigStore`,
  so an unsaved edit survives navigation between them within a session and appears in the Diff tab.
  The draft is not persisted: it is lost when the app closes, so save before exiting.
- **English recommendation text.** Recommendation titles, actions and verification steps come from
  the engine and stay in English; only the surrounding UI is translated (en/ru/zh).
- **No job progress or cancel.** Long engine calls show a busy state without a percentage, and there
  is no cancel button yet. Wait for the call to finish.
- **Preview scope.** This is a `0.x` build: configuration output and UI details may change before
  1.0.

## Data and privacy

The desktop uploads nothing on its own. Reports, snapshots, crawl data and the SQLite database stay
in the paths configured in `seo.toml`. Diagnostics are user-triggered and redacted. Provider calls
are made by the engine with the user's own credentials.

## Reporting problems

Open an issue at
<https://github.com/LevapVeeskela/lv24-seo-optimizer-desktop/issues> and include the desktop and
engine versions from the Configuration screen, the Windows version and the exact command or screen
that failed. Do not paste tokens, `seo.toml` secrets or customer queries. Security issues go through
[`SECURITY.md`](../../SECURITY.md), not a public issue.
